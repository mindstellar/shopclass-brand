# Asset build tools

The SVGs in `../brand/` are generated by these scripts.

- `build_svgs.py` — assembles all logo/icon/board SVGs from icon geometry + `paths.json`. Run: `python3 build_svgs.py` (stdlib only).
- `text2path.py` — regenerates `paths.json` (text converted to outlines). Only needed if wording/weights change. Requires `pip install fonttools` and the variable TTFs for Manrope and Inter (OFL, from github.com/google/fonts) next to `spec.json`. Run: `python3 text2path.py spec.json paths.json`.
- `spec.json` — which strings/fonts/weights to outline.
- `paths.json` — pre-generated outlines (checked in so `build_svgs.py` works standalone).

Favicon PNG/ICO files were rasterized from `brand/favicon/shopclass-favicon.svg` (headless Chrome at each exact size; ICO packs the 16/32/48 PNGs).
